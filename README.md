# Website template

## How to use
- Browse to the [repository template](https://github.com/jmcarman/template.github.io) on GitHub
- Click **Use this template** in the right corner
- Select **Your GitHub username** or **organization** from the **Owner** dropdown menu.
- In the **Repository name** field enter the name for your new repository.
- Set the visibility to **Private** OR **Public**.
- Scroll to the bottom and click **Create repository**.

## Configuring GitHub Pages
- In your **GitHub Repository** click on **Settings*
- Under **Branch** select **main**, and click **Save**
- Follow the steps outlined in **Initial setup** below.
- If you are using a **Custom domain** insert it in the text box and click **Save**.

## Initial setup
- Configure url in _config.yml to include 
    - **your GitHub pages url**
    - **your GitHub pages base url**
    - Update **Author** to your name
    - Update **Description** with your website description
    - Update **license** if you are not using **CC BY-SA**

- Modify **nav.md** to include links to any pages you want in the main navigation bar **on every page**.
- Follow the sample formatting in **index.md**, **lab1.md**, **lab2.md**
- If you wish to change your website colours, update **assets/style.css**
